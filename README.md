# De la API REST a Blazor: Introducción al Desarrollo .NET

> *«Conecta backend y frontend mediante C# y transferencia de datos»*

En este espacio construiremos una solución Fullstack de extremo a extremo utilizando el ecosistema de **.NET**: una **Minimal API** en el backend y una interfaz reactiva en el cliente con **Blazor WebAssembly**.

---

## 📌 Contenido del Taller

1. **Arquitectura .NET:** Entendiendo el flujo cliente-servidor y la ejecución de C# en el navegador con WebAssembly.
2. **Modelos Compartidos:** Reutilización de DTOs entre cliente y servidor sin duplicación de código.
3. **Backend REST:** Construcción de endpoints `GET` y `POST` con Minimal APIs y pruebas en Swagger.
4. **Frontend con Blazor WASM:** Consumo de APIs vía `HttpClient`, enlace de datos bidireccional y componentes Razor reactivos.
5. **Buenas prácticas:** Estructuración de proyectos fullstack en la industria.

---
